nerve-verify — Asset Action Receipt Verifier

Verifies a receipt's structure, timestamp, and Ed25519 signature entirely in-browser. No network calls. No server. Works opened as a local file.
Drop a receipt .json file here
or click to choose a file
All verification runs locally via the browser's WebCrypto API — the receipt file never leaves this page. Hash fields (input_hash/output_hash) are reported as "present, not independently verified" unless you separately supply the original payload; this tool never claims a hash check it did not actually perform.
